=== `Options`

`Options` configures validation and implementation deployment:

`referenceContract`:: Current or historical implementation used for storage
layout comparison. If empty, the new contract must provide
`@custom:oz-upgrades-from` when a reference is required.

`referenceBuildInfoDir`:: Absolute path, or project-relative path, to trusted
historical build-info.

`constructorData`:: ABI-encoded implementation constructor arguments. This is
not proxy initializer data.

`exclude`:: Source-path glob patterns excluded from validation. References are
not excluded.

`unsafeAllow`:: Comma-separated upgrades-core validation errors to waive.

`unsafeAllowRenames`:: Allows compatible storage variables to be renamed.

`unsafeSkipProxyAdminCheck`:: Skips the transparent proxy initial-owner safety
check.

`unsafeSkipStorageCheck`:: Skips storage-layout compatibility checks.

`unsafeSkipAllChecks`:: Skips all safety and compiler-provenance validation.

`linkedLibraries`:: Exact `LinkedLibrary` records used to link validated
creation bytecode in memory.

=== `LinkedLibrary`

`sourceName`:: Case-sensitive compiler source name from the link reference.

`libraryName`:: Case-sensitive library name from the link reference.

`libraryAddress`:: Deployed address containing the library's code.

Every mapping must be used, duplicate identities are rejected, and a prelinked
artifact must not receive mappings.

Defender options and transaction overrides are not part of this TVM API.
