=== `LegacyUpgrades.sol:Upgrades`

The validated legacy library exports these 13 upgrade-only functions and
overloads for existing OpenZeppelin Contracts v4 deployments:

* `upgradeProxy(address, string, bytes, Options)`
* `upgradeProxy(address, string, bytes)`
* `upgradeProxy(address, string, bytes, Options, address)`
* `upgradeProxy(address, string, bytes, address)`
* `upgradeBeacon(address, string, Options)`
* `upgradeBeacon(address, string)`
* `upgradeBeacon(address, string, Options, address)`
* `upgradeBeacon(address, string, address)`
* `validateUpgrade(string, Options)`
* `prepareUpgrade(string, Options) -> address`
* `getAdminAddress(address) -> address`
* `getImplementationAddress(address) -> address`
* `getBeaconAddress(address) -> address`

=== `LegacyUpgrades.sol:UnsafeUpgrades`

The unsafe legacy library exports these seven functions and overloads:

* `upgradeProxy(address, address, bytes)`
* `upgradeProxy(address, address, bytes, address)`
* `upgradeBeacon(address, address)`
* `upgradeBeacon(address, address, address)`
* `getAdminAddress(address) -> address`
* `getImplementationAddress(address) -> address`
* `getBeaconAddress(address) -> address`

Neither library deploys proxies, beacons, or standalone implementations.
`validateImplementation` and `deployImplementation` are intentionally absent.
New deployments use the modern API.

Local tests cover v4-style UUPS `upgradeTo`, ProxyAdmin `upgrade` and
`upgradeAndCall`, and strict v5 dispatch. External stock-TRE compatibility
evidence with pinned `@openzeppelin/contracts@4.9.6` and
`@openzeppelin/contracts-upgradeable@4.9.6` is pending. The API does not claim a
TRON-branded OpenZeppelin Contracts v4 package.
