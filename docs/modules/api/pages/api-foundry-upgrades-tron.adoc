= OpenZeppelin Foundry Upgrades for TRON API

== Contract name formats

`contractName`, and `referenceContract` without a historical directory, accept
a Solidity file name (`Box.sol`), a fully-qualified Foundry name
(`Box.sol:Box`), or an artifact path relative to the project root
(`out/Box.sol/Box.json`).

`@custom:oz-upgrades-from` accepts a contract name or compiler fully-qualified
name. When `referenceBuildInfoDir` is set, prefix that reference with the
directory's unique short name, for example
`build-info-v1:contracts/Box.sol:Box`.
