=== `Upgrades`

The validated library exports these 23 modern functions and overloads:

* `deployUUPSProxy(string, bytes, Options) -> address`
* `deployUUPSProxy(string, bytes) -> address`
* `deployTransparentProxy(string, address, bytes, Options) -> address`
* `deployTransparentProxy(string, address, bytes) -> address`
* `upgradeProxy(address, string, bytes, Options)`
* `upgradeProxy(address, string, bytes)`
* `upgradeProxy(address, string, bytes, Options, address)`
* `upgradeProxy(address, string, bytes, address)`
* `deployBeacon(string, address, Options) -> address`
* `deployBeacon(string, address) -> address`
* `upgradeBeacon(address, string, Options)`
* `upgradeBeacon(address, string)`
* `upgradeBeacon(address, string, Options, address)`
* `upgradeBeacon(address, string, address)`
* `deployBeaconProxy(address, bytes) -> address`
* `deployBeaconProxy(address, bytes, Options) -> address`
* `validateImplementation(string, Options)`
* `deployImplementation(string, Options) -> address`
* `validateUpgrade(string, Options)`
* `prepareUpgrade(string, Options) -> address`
* `getAdminAddress(address) -> address`
* `getImplementationAddress(address) -> address`
* `getBeaconAddress(address) -> address`

The overloads ending in `tryCaller` are for tests; broadcast scripts configure
the correct sender in Forge. Deployment functions return Forge-predicted
addresses. Resolve the actual TVM address when leaving the adapter-backed Forge
workflow.

UUPS and transparent deployment require non-empty initializer data. Beacon
proxy initialization is optional. Upgrade validation requires a reference
unless storage checks are explicitly skipped.

=== `UnsafeUpgrades`

The unsafe library exports these 11 modern functions and overloads:

* `deployUUPSProxy(address, bytes) -> address`
* `deployTransparentProxy(address, address, bytes) -> address`
* `upgradeProxy(address, address, bytes)`
* `upgradeProxy(address, address, bytes, address)`
* `deployBeacon(address, address) -> address`
* `upgradeBeacon(address, address)`
* `upgradeBeacon(address, address, address)`
* `deployBeaconProxy(address, bytes) -> address`
* `getAdminAddress(address) -> address`
* `getImplementationAddress(address) -> address`
* `getBeaconAddress(address) -> address`

`UnsafeUpgrades` does not validate implementation safety, storage compatibility,
or compiler provenance. It is intended for controlled tests and coverage, not
as a substitute for validated deployment scripts.

The `TRC1967InitializationRequired` error reports the TVM requirement for
non-empty UUPS and transparent initializer data.
